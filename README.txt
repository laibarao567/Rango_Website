RANGO — ADVANCED E-COMMERCE WEBSITE
===================================

Run locally with PHP (recommended):
1. Install XAMPP/WAMP or PHP 8+.
2. Put this folder inside htdocs (for XAMPP).
3. Start Apache.
4. Open: http://localhost/rango_upgrade/index.php

New advanced features:
- Premium animated hero and page loader
- Scroll reveal animation system
- Interactive image depth / pointer motion
- Animated marquee and micro-interactions
- Search overlay and category filters
- Product quick-add, wishlist and animated cart drawer
- Free-delivery progress indicator
- Product detail modal
- PHP API for newsletter, custom orders and checkout
- JSON storage fallback in data/ when PHP is available
- LocalStorage fallback for frontend-only use
- Responsive mobile experience
- Reduced-motion accessibility support

PHP endpoints are handled by api.php.
